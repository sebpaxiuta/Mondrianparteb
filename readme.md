# Mondrian parte 2

Para construir a Parte B, mantive a estrutura geométrica da composição através de um canvas estático de 800 por 800 píxeis com um fundo cru. Removi a instrução que bloqueia o ciclo para permitir a animação contínua do ecrã. No bloco de cor vermelha, apliquei uma função para criar uma oscilação de cor suave. Adicionei também um pequeno efeito de tremor na linha vertical principal, pois garante um dinamismo subtil que respeita a rigidez da obra original.
